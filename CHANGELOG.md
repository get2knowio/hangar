# Changelog

All notable changes to Hangar are documented here. From **0.3.12** onward this file is
maintained automatically by [release-please](https://github.com/googleapis/release-please)
from [Conventional Commit](https://www.conventionalcommits.org/) history — each entry is
generated when a release PR is merged.

Releases up to and including **0.3.11** predate this automation; see the
[GitHub Releases](https://github.com/get2knowio/hangar/releases) page for their notes.
